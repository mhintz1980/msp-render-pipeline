GPU enforcement is CYCLES-only (EEVEE + `require_gpu` still renders on CPU);

hashes (no soundness break — `job_id` still changes on tamper).

### T05 — done, two review rounds deep

The compositor now: places a supplied file mask through the same transform as
the product (the old code pasted offset pixels through an un-offset mask —
proven empirically to paint a black band on the leading edge and drop the
trailing strip; latent, no live caller was hit), runs the fidelity gate on the

fully-opaque pixels) is a failure, not a pass. `cmd_composite` exits 1 on any
gate failure. **Identity placement is byte-identical to the previous
implementation** (verified executionally against HEAD, both mask paths), so the
accepted v12 digests stand.
